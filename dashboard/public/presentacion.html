El programa de la tarjeta

Un solo archivo Arduino controla el sensor, la pantalla, el LED y la conexión.

C++ / Arduino IDE
firmware/sentido/sentido.ino.ino
void loop() {
  unsigned long now = millis();
  if (now - tSensor >= SENSOR_EVERY_MS) {
    tSensor = now; readAndSend();
  }
  if (now - tCommand >= COMMAND_EVERY_MS) {
    tCommand = now; pollCommand();
  }
  // … redibujar pantalla y actualizar LED
}

Extracto del ciclo principal. El archivo también valida las lecturas y reconecta el Wi-Fi.

Impacto

El mundo real como contexto
para procesos agénticos

Sentido conecta una medición física con un agente que puede consultarla y usarla dentro de un proceso.

01 / MEDICIÓN

El entorno aporta datos

El sensor observa temperatura y humedad.

02 / CONTEXTO

El agente puede consultar

MCP expone mediciones e historial.

03 / DECISIÓN

El dato entra al proceso

Codex consulta valores y configura reglas.

04 / ACCIÓN

La instrucción tiene efecto

Una regla envía correo. Codex controla OLED y LED.
